# Product

- **Kolkata Green Corridor** is a research demo about camera-based adaptive traffic signals and safe ambulance priority for crowded Indian cities, with Kolkata as the first case. It shows one simulated four-arm Kolkata-style junction with vehicle-count-based timing, skipping empty approaches, and **safe** ambulance priority, in three modes with a fallback ladder.
- It uses **simulated data only**. Every screen, chart, README section and video that shows results must say "Simulated data, not field results".
- The owner, Rajdeep, is not a programmer. After every task, explain in plain English: what changed, why, and exactly how to check it (a command to run or a thing to click).
- Do one task per prompt, then stop. Don't start the next task unasked.
- Evidence labels: when docs state a fact or number, mark it FACT, CLAIM, ESTIMATE or ASSUMPTION. Never invent statistics, studies or sources. Model inputs (vehicle shares, arrival rates) are ASSUMPTIONS and live in one config file.
- Halloween theme is light only ("an ambulance racing through Kolkata's haunted gridlock"); never at the cost of the safety message or readability.
- Bilingual sign on the dashboard: English and Bengali ("AMBULANCE APPROACHING, CLEAR LANE" / "অ্যাম্বুলেন্স আসছে, রাস্তা ছাড়ুন").
- Kiroween judges score five things equally: potential impact, how deeply Kiro is used, design (a complete, polished product, not a proof of concept), innovation, and the video. Build for all five.
- The core story for every screen and the video: "Kolkata Police already give organ transports a green corridor by hand. This demo shows how every ambulance could get one, safely."
- Category: Frankenstein (a traffic simulator, a safety lock, simulated camera/siren/GPS detection and a web dashboard stitched together).
